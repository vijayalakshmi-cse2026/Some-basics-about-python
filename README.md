# Python Programming Practice

## About the Project

This repository contains my beginner-level Python programming exercises using Jupyter Notebook. It documents my learning journey through fundamental Python concepts and practical code examples.

The exercises focus on understanding Python syntax, working with variables and data types, accepting user input, using operators, manipulating strings, generating random numbers, and implementing conditional statements.

## Objectives

- Understand the fundamentals of Python programming.
- Learn how to declare variables and assign values.
- Explore Python's built-in data types.
- Practice input and output operations.
- Understand arithmetic, comparison, logical, membership, and identity operators.
- Work with strings and string slicing.
- Apply conditional statements to solve simple problems.
- Develop programming confidence through practical exercises.

## Topics Covered

### 1. Variables and Assignment
- Assigning values to variables
- Assigning values to multiple variables
- Working with integers and strings

### 2. Data Types
- Integers (`int`)
- Floating-point numbers (`float`)
- Complex numbers (`complex`)
- Strings (`str`)
- Checking data types using `type()`

### 3. Input and Output
- Reading input using `input()`
- Displaying output using `print()`
- Formatting output with `sep` and `end`
- Converting input into integers and floating-point numbers

### 4. Operators
- Arithmetic operators
- Comparison operators
- Logical operators
- Assignment operators
- Membership operators (`in`, `not in`)
- Identity operators (`is`, `is not`)
- Exponentiation (`**`)

### 5. String Operations
- String indexing
- String slicing
- Membership testing
- Working with single-line and multiline strings

### 6. Conditional Statements
- `if`
- `if-else`
- `if-elif-else`
- Comparing numbers
- Checking whether a number is even or odd

### 7. Built-in Functions
- `type()`
- `chr()`
- `ord()`
- `bin()`
- `float()`

### 8. Random Number Generation
- Importing the `random` module
- Generating random integers using `random.randrange()`

## How to Run

1. Install Python 3.
2. Install Jupyter Notebook if it is not already installed.
3. Download or clone this repository.
4. Open a terminal in the project directory.
5. Run the following command:

```bash
python -m pip install notebook
jupyter notebook
```

6. Open `python_fundamentals.ipynb`.
7. Run the code cells individually and experiment with the examples.

Some exercises require user input, so enter the requested values when prompted.
